# EDR — The sweep for relocating the delta-spec fold reaches eight sites outside the ratified Affected Areas, including the domain's own repo README

- **Status:** Accepted
- **Date:** 2026-09-04

## Contexto
Relocating the delta-spec fold from `sdd-archive` to `sdd-apply` left prose scattered across the payload that states, as fact, that `sdd-archive` performs the fold. The proposal's ratified Affected Areas table named seven files to change. A sweep for every OTHER site making the same now-false claim found eight more, one of which — the domain's own `README.md` — does not fit the runtime-read criterion the three existing sweep-scope EDRs (`gating-vocabulary-sweep-scope`, `sdd-propose-contract-joins-lane-sweep`, `falsified-clause-joins-the-sweep`) already established, because that file is never deployed and no agent reads it at runtime.

## Decisión
The sweep reaches every site that states, in prose an agent OR a maintainer reads, that `sdd-archive` performs the fold — not only the seven files the proposal's Affected Areas table listed. Eight further sites join: `agents/sdd-archive.md` and `agents/sdd-apply.md` (runtime-read, the executor's own launch instructions); `references/spec/README.md` (runtime-read, and the canonical concept home the archive skill and the store both cite); the three `references/spec/templates/*.md` header comments; `skills/gentle-ai/sdd-spec/SKILL.md`'s two "at archive" citations; `skills/matecito-ai/development-spec-{bootstrap,validate}/SKILL.md`; `.matecito-ai/development-specs/INDEX.md`'s own maintenance bullet; and — the one case the three precedent EDRs do not cover — `payload/domains/development/README.md`, repo documentation that never deploys (`internal/setup/deploy/deploy.go` copies only `agents/`, `skills/`, `references/`, `scripts/` and `CLAUDE.md`). What goes stale there is not an incidental noun but a whole Read/Write table row that becomes flatly false — the shape `sdd-propose-contract-joins-lane-sweep.md` already puts inside the sweep, just not proven to reach a repo-only file before now. Two further mentions of `sdd-archive` stay untouched because they remain true after this change: `_shared/engram-convention.md`'s `archive-report | sdd-archive` row, and `sdd-onboard/SKILL.md`'s walkthrough step.

## Reglas verificables
- **[manual]** A sweep for a relocated flow-mechanism reaches every site whose prose states the mechanism as fact — runtime-read or not — when what goes stale is a structural claim (a table row, a whole sentence describing the mechanism), not an incidental noun.
- **[manual]** `payload/domains/development/README.md`'s `SDD Phase Read/Write` table row for `sdd-archive`/`sdd-apply`, and its "al archivar, sdd-archive mergea el delta" paragraph, are corrected in the same commit as the relocation, even though the file never deploys — because the false claim is a table row, not a stray word.
- **[manual]** `_shared/engram-convention.md`'s `archive-report | sdd-archive` row and `sdd-onboard/SKILL.md`'s walkthrough step stay untouched — both remain true after this relocation, since `sdd-archive` still writes the archive report and is still walked through onboarding.

## Alternativas consideradas
Leave every site outside the ratified Affected Areas table as accepted residue, per `structure/retired-vocabulary-in-record-stores.md` — rejected for the runtime-read sites by the criterion its two siblings already fix (`gating-vocabulary-sweep-scope.md`: a runtime-read file left pointing at something that no longer resolves joins the sweep; `sdd-propose-contract-joins-lane-sweep.md`: a whole sentence describing a retired mechanism is not an incidental stale noun). `structure/falsified-clause-joins-the-sweep.md` adds that the correction lands in the same commit as the rest, so nothing mid-change states both claims side by side. None of the three precedents, taken alone, reaches a repo-only file that never deploys — this decision extends the same reasoning (a structural claim, not an incidental noun) to that one case, rather than leaving it as residue by default.

## Consecuencias
This exceeds the confirmed proposal Scope (seven files) by eight further files, one commit, raised at the design gate rather than absorbed silently. A future relocation of a different flow-mechanism inherits the same test: a runtime-read site with a falsified structural claim joins the sweep by the existing three EDRs; a repo-only site with a falsified structural claim (table row, whole sentence) joins by this one; an incidental stale noun, in either kind of file, stays as accepted residue.
