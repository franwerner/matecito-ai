# EDR — Internacionalización y localización

- **Status:** Accepted
- **Type:** decision
- **Date:** 2026-07-23

## Contexto

El cockpit es single-user con un copy cálido argentino. No hay necesidad de multiidioma, pero conviene no enterrar los strings de UI en la lógica por si algún día aparece.

## Decisión

Un solo idioma (español), sin i18n formal. Convención mínima: los strings de UI no van enterrados en la lógica de negocio. Si algún día se necesita multiidioma, el camino sería i18next con JSON de locales.

## Reglas verificables

- **[manual]** un solo idioma (es), sin librería de i18n.
- **[manual]** los strings de UI no van hardcodeados en la lógica de negocio.
