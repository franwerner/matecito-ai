# SDK Go oficial de MCP

- **Category:** Other
- **Version:** sin pinear
- **Status:** Accepted
- **Decided in phase:** contracts
- **Date:** 2026-07-24

## Por qué la elegimos

Es el SDK oficial de MCP para Go (`github.com/modelcontextprotocol/go-sdk`) y soporta el transporte streamable HTTP que usa la superficie MCP del broker. Al ser el SDK oficial, sigue la spec del protocolo sin capa de traducción propia.

## Alternativas descartadas

- Ninguna evaluada formalmente (es el SDK oficial del protocolo).

## Notas

Usado en: contracts/mcp-server (superficie MCP cara a Claude, transporte streamable HTTP).
